**A receipt is a self-report, and on 2026-09-10 the orchestrator skipped one under pressure in the same session that
wrote this file.** That is why GR-5 and GR-6 are now an **Opus-only `Stop` hook**: it reads the real `git status` and
the actual Opus response, and exits 2 — the response is blocked and must be fixed before it can finish. Once the role
is identified as Opus it also fails closed on a gate error; only an absent role signal exits without imposing an
Opus-only Git handoff on Sonnet. It honours `stop_hook_active`, so it cannot loop.
