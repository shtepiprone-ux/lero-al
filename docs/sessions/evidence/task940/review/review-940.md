  directly, and review rewrites are governed by D2 and the review itself. For the 935 contract (absent at `origin/main`)
  this approver performed the anchor check by hand (probe above).

  section; accepted.

  receipt contract can still exempt itself and its evidence path if those happen to be receipt scope files. Only
  `tasks/**.security.json` and `docs/sessions/evidence/**` paths can be exempted, never gate code, and an implementer
  always writes gate code, so independence is not defeated.
