## Key design decisions

**Error selector**: `[data-error]:not(:checked)` (0,3,0) placed AFTER the resting rule `[not(:checked)]:not([data-checked])` (0,3,0) — same specificity, wins by source order. This mirrors the Task 497 Checkbox fix and is pre-verified from Radio.mjs L137 `mod:{error:!!error}`.

**Checked+error**: `[data-error]:checked` (0,3,0) → brand border. In the story, demonstrated via `Radio.Group defaultValue` (provides checked context) + `error` prop directly on the `Radio` (provides `data-error`).

**Disabled checked demo**: `Radio.Group defaultValue="e2"` with `<Radio value="e2" disabled>` — the group selects it (checked) but disabled prevents interaction.
