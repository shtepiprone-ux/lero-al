PROOF G3 - why the PerfDevOverlay Part B witness measures rgb(0, 0, 0) on both sides.

Variable chain for .text-destructive:
  bundle rule           .text-destructive{color:var(--destructive)}
  globals.css:411      --destructive:         var(--brand-900);      (inside :root, line 350)
  globals.css:365      --brand-900: var(--mantine-color-brand-9);  /* #8E322B */

MantineProvider injects the --mantine-color-* set at RUNTIME. A harness page that serves
only the concatenated .next/static/css therefore leaves the chain unresolved, the
declaration is invalid at computed-value time, and color falls back to the UA default for
a <button> (canvastext) = rgb(0, 0, 0). That is a measurement artefact of the harness, not
a value either phase of the app renders. A fail-closed comparator should reject an
initial-value fallback rather than score it as a match.
