options list content box (padR=17px below) — headless Linux paints 0-width overlay
scrollbars, Windows Chrome paints a classic ~17px one, and that 17px is what tipped
every row over the edge in the owner's screenshot.

Budget arithmetic the two numbers come from (all values read out of theme.ts, not guessed):
  dropdown padding  24  (Combobox.styles.dropdown 0.75rem x2)
  option padding    24  (Combobox.styles.option 0.625rem 0.75rem)
  border             2
  Group gap="sm"    12
  CheckIcon         14  (selected row only — and the selected row is the one that broke)
  scrollbar         17  (mah={220} always overflows for 12 months / 6+ years)
  -------------------
  fixed chrome      93  ->  min width = widest label + 93
  month: 64.6 + 93 = 158  -> set 190 (32px locale headroom)
  year:  32.0 + 93 = 125  -> set 140 (15px headroom; a year label is always 4 digits)
