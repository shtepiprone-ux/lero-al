# External references (checklist U10)

Used only for a UI decision no canonical component covers (`canonical-component-reuse.md`, owner decision 2026-10-20).

- [ ] Start from `docs/research/references/<newest date>/`; check that each page relied on still says the same.
- [ ] Standing references: Lahomes, Kamr (demo login, `project-facts.md`), Omah, TailAdmin, and any URL the owner gives:
      inspect the pages that show the decision, operate the relevant states, decide each element the owner's reference
      shows. A page that cannot be opened is `UNVERIFIED` and supports nothing.
- [ ] A responsive decision also cites a primary source of `mobile-adaptation-contract.md` (W3C Reflow, Apple HIG
      Layout, Android Adapt layouts): the URL, the guidance, the pattern ID chosen and why the surface fits it.
- [ ] The kickoff (design) or the review records the pages used with their URLs and the pattern chosen; there is no
      receipt string. Detail: `docs/rules/golden/gr-7-reference-research.md`.
