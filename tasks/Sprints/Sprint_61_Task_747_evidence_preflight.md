## 2. The machine source of truth already exists — measured, not assumed

`scripts/check-review-ledger.mjs:917-936`, `validateCoverageSummary`, recomputes the whole summary from the
ledger's own rows and rejects any declared value that differs:

```js
const expected = {
  total:      primaryRows.length,
  verified:   primaryRows.filter(r => r.status === 'VERIFIED').length,
  unverified: primaryRows.filter(r => r.status !== 'VERIFIED').length,
  openP0: findings.filter(f => f.priority === 'P0' && f.status === 'OPEN').length,
  openP1: findings.filter(f => f.priority === 'P1' && f.status === 'OPEN').length,
  openP2: findings.filter(f => f.priority === 'P2' && f.status === 'OPEN').length,
};
// … must equal the ledger-derived value <expected>
```

**So `review.coverage` cannot lie, and 747 does not need to build a source of truth — only a projection check.**
That reframing is the single most useful fact in this preflight and it is why the task is small.
