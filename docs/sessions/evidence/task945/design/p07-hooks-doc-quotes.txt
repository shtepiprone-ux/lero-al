Source: https://code.claude.com/docs/en/hooks, read 2026-11-04 through the web-fetch agent; verbatim quotes.
PostToolUse exit 2: "`PostToolUse` | No | Shows stderr to Claude; the tool already ran"
PostToolUse: "To surface a warning to Claude from a `PostToolUse` or `PostToolUseFailure` hook, exit 2 instead so Claude sees the stderr even though the tool already ran."
Stop exit 2: "`Stop` | Yes | Prevents Claude from stopping, continues the conversation"
Stop reason: "A hook that blocks by exiting 2 routes the same way as `reason`: Claude receives the stderr message as the explanation for why it should continue."
Stop loop: "Claude Code applies an 8-consecutive-continuation cap: after stop hooks have continued the turn eight times in a row, Claude Code overrides the next block and ends the turn."
Timeout: "Claude Code cancels a `command`, `http`, or `mcp_tool` hook that reaches its [`timeout`], discarding the hook's output, so on most events a timed-out hook renders no decision."
Subagents: "tool events such as `PreToolUse` and `PostToolUse` fire the same configured hooks as in the main conversation"
SubagentStop: "Runs when a Claude Code subagent has finished responding."
Not stated in the text read: the maximum hook timeout. The 8-continuation cap means a failing Stop gate cannot trap a session for ever; the turn then ends with the failure shown.
